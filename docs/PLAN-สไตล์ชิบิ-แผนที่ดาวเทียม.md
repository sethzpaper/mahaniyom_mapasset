# แผนปรับวิดีโอให้เป็นสไตล์อินโฟกราฟิกเล่าเรื่อง (9:16)

สถานะ: **แผน** — วิดีโอรุ่นแรก (`video/mahaniyom_isan_monks_9x16.mp4`, สร้างจาก `video/render.py`) เป็นแบบการ์ดภาพถ่ายนิ่งบนแผนที่วาด ยังไม่ใช่สไตล์ต้นแบบ

## สไตล์ต้นแบบ (จากภาพตัวอย่างที่ผู้ใช้ส่ง)
- ฉากหลังแผนที่ภูมิประเทศดาวเทียม ซูมบิน/เอียงมุม
- ตัวนำทางเป็นพระน้อยสไตล์ชิบิ ในกรอบรูปไข่สีทอง ปักบนแผนที่ + หมุดเหลือง
- ฉากเล่าเรื่องเป็นการ์ตูนนุ่มๆ ซ้อนชั้น (ฟ้า ฉากกลาง ฉากหน้า) ตัวละครอยู่หน้าฉาก
- เงาประเทศ/จังหวัดเติมสี พร้อมตัวเลขใหญ่เน้นสีเหลือง
- ซับไตเติลตัวหนาสีขาวใหญ่ทับฉาก

## งานฝั่งโค้ด (ทำหลังได้ภาพ — ใช้ภาพชั่วคราวก่อนได้)
1. กล้องบินเอียงมุมบนภาพภูมิประเทศ ซูมจากทั้งภูมิภาคเข้าอีสาน
2. ตัวชิบิเคลื่อนไปตามเส้นทางจังหวัดต่อจังหวัด พร้อมหมุดเหลือง
3. ฉากเล่าเรื่องแบบ parallax ต่อพระ 1 รูป ตรงตามคิวเวลาใน `research-kajiwat/09-คิวภาพเบื้องต้น.md`
4. ซับไตเติลตัวหนา มีไฮไลต์สีเหลืองที่ตัวเลข
5. ฉากเงาประเทศ/จังหวัดเติมสี พร้อมตัวเลขใหญ่
6. อัปเดต `video/render.py` และเรนเดอร์ใหม่ที่ 1080×1920

## ข้อควรระวังที่ต้องคงไว้
- หลวงปู่ผางมรณภาพ พ.ศ. 2525 และหลวงปู่ทองมา พ.ศ. 2534: ไม่ทำฉากท่านมีชีวิตในปีหลังจากนั้น (ดู `00-ภาพรวม.md`)
- ไม่แสดงปี พ.ศ. ของหลวงตามหาบัวจนกว่าจะฟังตรวจเสียง
- ภาพภายนอกที่นำมาใช้ต้องตรวจสิทธิ์การใช้งานก่อนเผยแพร่

## ขั้นตอน
1. ผู้ใช้เพิ่มภาพตามตารางข้างบน (ไม่ต้องครบทุกชิ้นก็เริ่มได้)
2. เพิ่ม prompt สร้างภาพชิบิและฉากให้สไตล์เดียวกัน (`prompts/`) ตามที่ตกลง
3. ปรับ `video/render.py` ตามงานฝั่งโค้ดด้านบน แล้วเรนเดอร์ใหม่
